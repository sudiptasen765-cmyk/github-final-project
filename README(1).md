# Simple Interest Calculator

## Project Description

The Simple Interest Calculator is a Bash-based command-line application that calculates simple interest based on user-provided values.

The calculator takes the following inputs from the user:

- Principal amount
- Rate of interest
- Time period

It then calculates the simple interest using the formula:

**Simple Interest = (Principal × Rate × Time) / 100**

## Features

- Accepts principal amount from the user.
- Accepts the rate of interest from the user.
- Accepts the time period from the user.
- Calculates simple interest automatically.
- Displays the calculated simple interest in the terminal.
- Uses a simple and easy-to-understand Bash script.

## Formula

```text
SI = (P × R × T) / 100
```

Where:

- **P** = Principal amount
- **R** = Rate of interest
- **T** = Time period

## Technologies Used

- Bash Shell
- Git
- GitHub

## How to Run

Make the script executable:

```bash
chmod +x simple-interest.sh
```

Run the calculator:

```bash
./simple-interest.sh
```

Enter the principal amount, rate of interest, and time period when prompted.

## Example

```text
Enter the principal amount: 10000
Enter the rate of interest: 5
Enter the time period: 2

Simple Interest: 1000
```
