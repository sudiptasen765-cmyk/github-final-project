# Contributing

Thank you for your interest in contributing to the Simple Interest Calculator project!

All contributions, bug reports, bug fixes, documentation improvements, enhancements, and ideas are welcome.

## How to Contribute

1. Fork the repository.
2. Create a new branch for your changes.
3. Make your changes and test them.
4. Commit your changes with a clear commit message.
5. Push your branch to your fork.
6. Open a pull request describing your changes.

## Bug Reports

When reporting a bug, please provide:

- A clear description of the problem.
- Steps to reproduce the issue.
- The expected behavior.
- The actual behavior.
- Any relevant terminal output or screenshots.

## Bug Fixes

Bug fixes are welcome. Please explain the problem being fixed and verify that the fix does not introduce new issues.

## Documentation Improvements

Improvements to the README, comments, instructions, examples, and other documentation are welcome.

## Enhancements and Ideas

Suggestions for new features, improvements, and ideas are encouraged. Please describe the proposed change and explain how it would improve the project.

## Code Quality

Please keep contributions clear, simple, and consistent with the existing project structure.

## Pull Requests

Please provide a descriptive title and explain what your pull request changes. Make sure the project works as expected before submitting your pull request.

## Code of Conduct

Please follow the project's Code of Conduct when participating in the project.
